How the system works

Four steps from raw measurements to a predicted crop.

{{ ic.icon('cpu', 18) }}
1

Collect inputs

Seven numeric values: N, P, K, temperature, humidity, soil pH and rainfall.

2

Validate

Missing, non-numeric or impossible values are rejected before the model runs. Unusual but possible values raise a warning.

3

Predict

The saved scikit-learn pipeline receives the features in training order and returns one of the {{ summary.dataset.n_classes or 22 }} crop labels.

4

Explain

The result card shows the crop, the model used, the submitted values and any warnings, with a clear disclaimer.

{{ ic.icon('info', 18) }}
The dataset contains no location, soil-type or season field, so this model cannot make district-specific claims. Treat the prediction as educational decision support.
