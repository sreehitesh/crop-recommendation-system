{{ ic.icon('info', 18) }} About this project

Crop Recommendation System Using Machine Learning - version {{ summary.app_version }}

This is a college-level machine learning project that predicts a suitable crop from seven soil and environmental measurements. It was built to demonstrate the full path from a public agricultural dataset to a deployed web application: data validation, model training and tuning, honest evaluation on a held-out test set, model persistence, a Flask JSON API, input validation, an automated test suite and complete documentation.

{{ ic.icon('check', 18) }} What is included

  • A real, verified agricultural dataset ({{ summary.dataset.rows or 2200 }} records, {{ summary.dataset.n_classes or 22 }} crop classes).
  • Three trained classifiers with cross-validated hyperparameters.
  • Measured accuracy, macro precision, macro recall, macro F1, per-class metrics and confusion matrices.
  • A saved pipeline used unchanged for every prediction.
  • Six dashboard pages: Overview, Crop Recommendation, Model Performance, Dataset Insights, Documentation, About.
  • Server-side and client-side validation with helpful messages.
  • An automated pytest suite for validation, prediction and HTTP routes.
  • Project documentation: dataset card, model card, user guide, technical documentation and test report.

{{ ic.icon('shield', 18) }} Responsible use

  • The prediction is a machine learning estimate, not agronomic advice.
  • Model accuracy measured on the test split is not the confidence of a single prediction.
  • Dataset range checks are warnings about missing training examples, not agricultural limits.
  • No location field exists in the data, so no district-specific claim is made.
  • Always confirm a crop choice with local soil tests, season, irrigation and expert guidance.
{{ ic.icon('alert', 18) }}
Not intended for yield prediction, fertiliser prescriptions, disease diagnosis, irrigation scheduling or commercial farm advisory use.

{{ ic.icon('book', 18) }} Credits and attribution

  • Dataset: Crop Recommendation Dataset, published on Kaggle by Atharva Ingle (Crop_recommendation.csv). The publisher describes it as built by augmenting Indian rainfall, climate and fertiliser data. It is used here for educational purposes; check the Kaggle page for the applicable licence before redistribution.
  • Dataset access: the download script fetches the same file from public mirrors and verifies that two mirrors agree before saving, because the Kaggle page requires an account.
  • Algorithms: scikit-learn implementations of CART decision trees, random forests and the support vector classifier.
  • Crop notes: brief neutral descriptions compiled from public general-agronomy references; they are context for a label, not recommendations, and are not used by the model.
  • Icons: inline SVGs in the Lucide style (ISC licence).

{{ ic.icon('target', 18) }} Scope

In scope

  • Seven-feature multi-class crop classification.
  • Three-algorithm comparison with reproducible evaluation.
  • Deployment of the selected model behind a Flask API and dashboard.
  • Documentation, tests and honest limitations.

Out of scope

  • Yield, profit or crop-success prediction.
  • Live weather or soil sensor integration.
  • District-specific recommendations.
  • Fertiliser, disease or irrigation advice; user accounts; cloud hosting.
